# Гранд-Палас Спорт — сайт спортивного клуба

Современный, статусный и «лёгкий» сайт спортивного клуба премиум-класса
**«Гранд-Палас Спорт»** (г. Всеволожск). Полностью статический (HTML/CSS/JS,
без сборки и зависимостей) — разворачивается на любом хостинге простым
копированием файлов.

Палитра — **белый + золото** (серый и красный из старого оформления не
используются). Акцент на качественных фото студии пилатеса, плавной анимации
и слайд-шоу — в соответствии с брифом.

## Слоган (предложение разработчика)

> **«Искусство быть в форме»**

Запасные варианты: «Пространство силы и баланса», «Спорт уровня премиум — в двух шагах от дома».

## Структура

```
index.html                     — главная (one-page со всеми разделами)
articles/                      — SEO-статьи
  pilates-vsevolozhsk.html
  kak-vybrat-fitnes-klub.html
  personalnyy-trener.html
assets/css/style.css           — все стили и анимации
assets/js/main.js              — вся интерактивность (vanilla JS)
assets/img/                    — оптимизированные фото (full + -thumb) и favicon
scripts/optimize_images.py     — пересборка веб-версий фото из оригиналов
robots.txt, sitemap.xml        — SEO
*.jpg (в корне)                — исходные рендеры от клиента (источник)
```

## Разделы сайта (по брифу)

1. Главный экран — слайд-шоу пилатес-залов с эффектом Ken Burns
2. О клубе + статистика (территория, корты, режим)
3. Направления — **студия пилатеса (приоритет, метка «новое»)**, тренажёрный
   зал, теннис, бассейн, персональные тренировки
4. Студия пилатеса — отдельный акцентный блок с параллаксом
5. Галерея с лайтбоксом
6. Преимущества (УТП)
7. Тренерский состав (карточки-заглушки — ждём фотосъёмку по ТЗ из брифа)
8. Статьи (SEO)
9. Контакты: адрес, телефоны (клик-звонок), почта, VK, форма заявки, Яндекс.Карта
10. Подвал + плавающая кнопка «Позвонить» (моб.)

## Анимация

Прелоадер с прорисовкой логотипа · кастомный курсор (десктоп) · слайд-шоу
с Ken Burns · reveal-анимации при скролле (IntersectionObserver) · анимация
счётчиков · параллакс · бегущая строка · hover-эффекты карточек · лайтбокс
с клавиатурой/свайпом · анимированное мобильное меню (clip-path).
Всё корректно отключается при `prefers-reduced-motion`.

## Фотографии

Все фото — реальные рендеры интерьеров клуба, оптимизированные для веба
(70 МБ → ~9,5 МБ). Сжатие/переименование выполняет `scripts/optimize_images.py`
(требует `pip install Pillow`):

```bash
python3 scripts/optimize_images.py
```

> **Важно:** в наличии только рендеры **студии пилатеса** и прилегающих зон.
> Для карточек «Теннис», «Бассейн», «Тренажёрный зал» временно использованы
> атмосферные интерьерные кадры. После получения реальных фото всех зон
> (бриф, п.14) их достаточно положить в `assets/img/` и обновить ссылки.

## Что нужно настроить перед запуском (бриф)

- **Яндекс.Метрика** — вставить счётчик в конец `index.html` (есть комментарий-плейсхолдер).
- **Форма заявки** — сейчас работает на фронтенде (показывает «Спасибо»).
  Готова к подключению к CRM / отправке на e-mail (бриф: зарезервировано на будущее).
- **Соцсети** — подключён VK (основной). Instagram/Telegram — после юридического
  согласования (бриф, п.9, п.14).
- **Партнёрские объекты** — добавить ссылки в подвал после уточнения формата (бриф, п.14).
- Косметология и уход за телом исключены — по требованию брифа.
